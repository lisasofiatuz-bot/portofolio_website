Photography Portfolio Website

📸 Tentang Website

Website portofolio fotografi pribadi yang menampilkan hasil karya foto, pengalaman, dan informasi mengenai fotografer. Website ini dibuat sebagai media untuk memperkenalkan karya fotografi secara online dengan tampilan yang menarik dan responsif.

🎯 Tujuan

- Menampilkan hasil karya fotografi.
- Memperkenalkan profil dan pengalaman fotografer.
- Memudahkan pengunjung melihat koleksi foto.
- Menjadi media portofolio digital.

✨ Fitur

- Home: Halaman utama website.
- About: Informasi tentang fotografer.
- Gallery: Koleksi hasil fotografi.
- Experience: Pengalaman fotografi.
- Contact: Informasi kontak.

🛠️ Teknologi

- HTML
- CSS
- JavaScript

📁 Struktur Folder

portfolio-website-fixed/
├── css/
├── documents/
├── images/
├── js/

└── README.md

🚀 Cara Menjalankan

1. Download atau clone repository.
2. Buka folder proyek di Visual Studio Code.
3. Buka file index.html.
4. Jalankan menggunakan browser atau Live Server.
